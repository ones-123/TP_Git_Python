# TP2 - Mon assistant de revision

## Presentation

Ce programme aide a organiser les revisions.

## Versions V1 a V4

V1 : Creation du programme avec un message de bienvenue.
V2 : Ajout du prenom de l'utilisateur et premier git push.
v3 : ajout de la matiere a reviser sur github, puis git pull
v4:ajout de la duree de revision et nouveau git push

## Comment executer le programme

1: Ouvrir le dossier TP_Git_Python dans VS Code.
2: Ouvrir le fichier main.py.
3: Cliquer sur Run Python File en haut a droite.
4: Entrer son prenom, la matiere et la duree en minutes.
5: le programme affiche un message avec les informations saisies

## Commandes Git utilisees

git init : Initialiser le projet Git.
git add : Preparer les fichiers.
git commit : Enregistrer les modifications.
git push : Envoyer les modifications sur GitHub.
git pull : Recuperer les modifications depuis GitHub.
